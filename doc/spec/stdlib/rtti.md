base standard library. These types form the reflection infrastructure of K,
allowing programs to inspect type metadata at runtime.

## 1. Overview

Every K `class` and `interface` carries an RTTI descriptor in vtable slot 0.
The standard library provides types that let user code access this metadata
at runtime via `Object::getClass()` (for classes) or through base arrays
(for interfaces).

The RTTI system supports:

- **Type identification** — get a type's short name and fully qualified name.
- **Inheritance introspection** — enumerate base types.
- **Nested type introspection** — enumerate nested types.
- **Enclosing type introspection** — find the enclosing type (for nested types).
- **Visibility and modifiers** — query visibility, static-ness.
- **Annotation introspection** — enumerate annotations attached to a type.

## 2. Visibility

```k
enum Visibility {
    PUBLIC = 0;
    PROTECTED = 1;
    PRIVATE = 2;
};
```

Enumerates the visibility levels of type declarations.

| Entry | Value | Description |
|-------|-------|-------------|
| `PUBLIC` | 0 | Accessible from any scope. |
| `PROTECTED` | 1 | Accessible from the declaring type and subclasses. |
| `PRIVATE` | 2 | Accessible only from within the declaring type. |

## 3. TypeInfo

```k
const interface TypeInfo {
    const getName() : const char[]?;
}
```

The base interface for all RTTI type descriptors. Provides the type's short
(unqualified) name.

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `getName()` | `const char[]?` | Short name of the type (e.g. `"String"`, `"Object"`, `"MyClass"`). |

## 4. AggregateType

```k
const interface AggregateType : public TypeInfo {
    const getFullName()    : const char[]?;
    const getBases()       : const TypeInfo?[]?;
    const getNested()      : const TypeInfo?[]?;
    const getEnclosing()   : const TypeInfo?;
    const getVisibility()  : Visibility;
    const isStatic()       : bool;
}
```

Extended interface for aggregate type descriptors (classes, interfaces,
annotation types). Inherits `getName()` from `TypeInfo`.

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `getFullName()` | `const char[]?` | Fully qualified name including module and namespaces (e.g. `"::k::String"`). |
| `getBases()` | `const TypeInfo?[]?` | Array of base type descriptors, or `null` if no bases. |
| `getNested()` | `const TypeInfo?[]?` | Array of nested type descriptors, or `null` if none. |
| `getEnclosing()` | `const TypeInfo?` | Enclosing type descriptor, or `null` if this is a top-level type. |
| `getVisibility()` | `Visibility` | Declared visibility of this type. |
| `isStatic()` | `bool` | `true` if this is a `static` nested type. |

## 5. Class

```k
final const class Class : public AggregateType
```

RTTI descriptor for class types. Each concrete class has exactly one
`Class` instance, generated by the compiler and stored in vtable slot 0.

### Fields (private)

| Field | Type | Description |
|-------|------|-------------|
| `name` | `const char[]?` | Short class name. |
| `fullName` | `const char[]?` | Fully qualified class name. |
| `bases` | `const TypeInfo?[]?` | Array of base type descriptors. |
| `nested` | `const TypeInfo?[]?` | Array of nested type descriptors. |
| `enclosing` | `const TypeInfo?` | Enclosing type descriptor (or `null`). |
| `flags` | `unsigned int` | Packed bit-flags (visibility + is_static). |
| `annotations` | `const Annotation?[]?` | Annotation instances attached to this class. |

### Methods

All methods from `AggregateType`, plus:

| Method | Returns | Description |
|--------|---------|-------------|
| `getAnnotations()` | `const Annotation?[]?` | Array of annotation instances, or `null` if unannotated. |

### Flags layout

| Bits | Meaning |
|------|---------|
| 0–1 | Visibility (matches `Visibility` enum: 0=PUBLIC, 1=PROTECTED, 2=PRIVATE). |
| 2 | `is_static` — `1` if the class is a `static` nested type. |
| 3+ | Reserved for future use. |

## 7. AnnotationType

```k
final const class AnnotationType : public AggregateType
```

RTTI descriptor for annotation types. Each annotation type declared in a
K program has exactly one `AnnotationType` instance, generated by the
compiler.

### Fields (private)

| Field | Type | Description |
|-------|------|-------------|
| `name` | `const char[]?` | Short annotation type name. |
| `fullName` | `const char[]?` | Fully qualified annotation type name. |
| `bases` | `const TypeInfo?[]?` | Base type descriptors (if any). |
| `nested` | `const TypeInfo?[]?` | Nested type descriptors (if any). |
| `enclosing` | `const TypeInfo?` | Enclosing type descriptor (or `null`). |
| `flags` | `unsigned int` | Packed bit-flags (visibility + is_static). |
| `annotations` | `const Annotation?[]?` | Meta-annotation instances attached to this annotation type. |

### Methods

All methods from `AggregateType`, plus:

| Method | Returns | Description |
|--------|---------|-------------|
| `getAnnotations()` | `const Annotation?[]?` | Array of meta-annotation instances attached to this annotation type, or `null` if unannotated. Used to inspect meta-annotations (`@Retention`, `@Inherited`, `@Target`) at runtime. |

## 8. Annotation

```k
const class Annotation {
public:
    final const getAnnotationType() : const AnnotationType&;
}
```

Root base class for all annotation instances. Every annotation type
implicitly inherits from `Annotation`.

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `getAnnotationType()` | `const AnnotationType&` | Returns the `AnnotationType` descriptor for the concrete annotation type. Reads vtable slot 0 (RTTI pointer). |

The method is declared `final` — it cannot be overridden. It delegates to
the C runtime helper `__k_annotation_get_type()` which extracts the RTTI
pointer from the annotation instance's vtable.

## 9. Type hierarchy

```
TypeInfo (interface)
  └── AggregateType (interface)
        ├── Class (final const class)
        ├── Interface (final const class)
        └── AnnotationType (final const class)

Annotation (const class)
  └── <user annotation types>
```

All three concrete descriptor types (`Class`, `Interface`, `AnnotationType`)
implement `AggregateType` and therefore `TypeInfo`.

`Annotation` is a separate hierarchy: it is the base for user-defined
annotation instances (not for type descriptors).

## 10. Usage examples

### Get the class name of an object

```k
import k;

test() : int {
    s : k::String("hello");
    name : k::String(s.getClass().getName());
    expected : k::String("String");
    if (name == expected) return 42;
    return 0;
}
```

### Get the fully qualified name

```k
import k;

test() : int {
    s : k::String("hello");
    fqn : k::String(s.getClass().getFullName());
    expected : k::String("::k::String");
    if (fqn == expected) return 42;
    return 0;
}
```

### Enumerate base types

```k
import k;

test() : int {
    s : k::String("hello");
    bases : const k::TypeInfo?[]? = s.getClass().getBases();
    if (bases == null) return 0;
    // String inherits from Object, so bases->size == 1
    return bases->size;   // → 1
}
```

### Polymorphic type identification

```k
import k;

get_class_name(o : k::Object&) : k::String {
    result : k::String(o.getClass().getName());
    return result;
}

test() : int {
    s : k::String("hello");
    name : k::String = get_class_name(s);
    expected : k::String("String");
    if (name == expected) return 42;
    return 0;
}
```

### Check for annotations

```k
import k;

annotation Marker {}

@Marker
class Target {
    public Target() {}
    public dummy() : int { return 0; }
}

test() : int {
    t : Target;
    anns : const k::Annotation?[]? = t.getClass().getAnnotations();
    if (anns == null) return 0;
    ann : const k::Annotation? = anns[0];
    if (ann == null) return 1;
    name : k::String(ann->getAnnotationType().getName());
    expected : k::String("Marker");
    if (name == expected) return 42;
    return 2;
}
```

### Inspect nested types

```k
import k;

class Outer {
    public Outer() {}
    public dummy() : int { return 0; }
    class Inner {
        public Inner() {}
        public value() : int { return 7; }
    }
}

test() : int {
    o : Outer;
    nested : const k::TypeInfo?[]? = o.getClass().getNested();
    if (nested == null) return 0;
    if (nested->size != 1) return 1;
    inner : const k::TypeInfo? = nested[0];
    if (inner == null) return 2;
    name : k::String(inner->getName());
    expected : k::String("Inner");
    if (name == expected) return 42;
    return 3;
}
```

## 11. Meta-annotation types

**Namespace:** `k::annotations`  
**Source:** `libk/libk/src/annotations.k`

The K standard library provides three meta-annotation types that control
how the compiler processes annotation instances. They are declared in the
`k::annotations` namespace and are automatically available in every K
module (via the implicit `import k;`).

All three meta-annotations are themselves annotated with
`@Retention(Policy::RUNTIME)` and `@Target({ElementType::ANNOTATION})`,
making them available for runtime inspection and restricted to annotation
type declarations.

### 11.1. Retention

```k
@Retention(Policy::RUNTIME)
@Target({ElementType::ANNOTATION})
annotation Retention {
    enum Policy { SOURCE; RUNTIME; };
    policy : Policy = Policy::RUNTIME;
}
```

Controls whether instances of the annotated annotation type are emitted into
the binary as RTTI metadata.

#### Inner enum `Retention.Policy`

| Entry | Value | Description |
|-------|-------|-------------|
| `SOURCE` | 0 | Annotation kept in compiler model only — not emitted to binary. |
| `RUNTIME` | 1 | Annotation emitted as an LLVM global constant in the RTTI. Default. |

#### Field

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `policy` | `Policy` | `Policy::RUNTIME` | The retention policy. |

### 11.2. Inherited

```k
@Retention(Policy::RUNTIME)
@Target({ElementType::ANNOTATION})
annotation Inherited {}
```

Marker meta-annotation. When applied to an annotation type, instances of that
annotation are automatically propagated from a base class to its derived
classes (via class inheritance only — not interface implementation).

If the derived class explicitly provides its own instance of the same
annotation type, the explicit instance replaces the inherited one.

No fields.

### 11.3. Target

```k
@Retention(Policy::RUNTIME)
@Target({ElementType::ANNOTATION})
annotation Target {
    enum ElementType { CLASS; INTERFACE; ANNOTATION; };
    value : ElementType[];
}
```

Restricts the kinds of program elements to which the annotated annotation
type may be applied. The compiler checks this at compile time and emits
error `0x003C` on violations.

#### Inner enum `Target.ElementType`

| Entry | Value | Description |
|-------|-------|-------------|
| `CLASS` | 0 | `class` declarations. |
| `INTERFACE` | 1 | `interface` declarations. |
| `ANNOTATION` | 2 | `annotation` type declarations. |

#### Field

| Field | Type | Description |
|-------|------|-------------|
| `value` | `ElementType[]` | Set of allowed element types. |

If `@Target` is absent from an annotation type, the annotation can be applied
to any supported element type. If present with an empty array, the annotation
cannot be applied anywhere.
